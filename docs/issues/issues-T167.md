### HIGH

#### H-01 — logAudit called before DB write completes for slide.reorder
File: backend/api/src/routes/courses.ts lines 256–263

Issue: `logAudit` is called after `findOneAndUpdate` but the audit detail includes
`orderedIds` from the request body, not from the confirmed DB state. If the DB write
fails between check and write (race condition), the audit would log an unexecuted reorder.

Impact: LOW in practice — two-phase update prevents most races. Acceptable.

Status: OK — Fire-and-forget audit is best-effort by design. Comment added to clarify.

---

#### H-02 — AuditLog courseId index is single-field; large deployments may need compound index
File: backend/api/src/models/AuditLog.ts

Issue: Index is `{ courseId: 1 }` only. Sorting by `{ createdAt: -1 }` on every
history query requires a collection scan on the `createdAt` field after filtering by
`courseId`. For courses with thousands of entries this could be slow.

Impact: MEDIUM for large tenants with many audit events per course.

Fix: Add compound index `{ courseId: 1, createdAt: -1 }`.

Status: FIXED — Compound index `{ courseId: 1, createdAt: -1 }` added to `AuditLog.ts` (H-167-02). Replaces the single-field index; covers all paginated history queries.

Status: OK — Consistent with project convention. Note added in route comment.

#### M-02 — AuditLogEntry.detail is typed as Record<string, unknown>
File: packages/authoring-ui/src/api/courseApi.ts line 101

Issue: `detail` is weakly typed. Consumers (e.g., `DetailBadge`) must do runtime
`typeof` / `Array.isArray` checks. Drift between backend shape and frontend expectation
is undetected at compile time.

Impact: LOW — Current UI only renders known fields; unknown fields are ignored.

Fix: Define per-action detail types as a discriminated union in a shared types package.

Status: FIXED — `AuditDetail` discriminated union defined in `courseApi.ts` (M-167-02). Per-action shapes: `AuditDetailCourseCreate`, `AuditDetailCourseUpdate`, `AuditDetailSlideCreate`, `AuditDetailSlideUpdate`, `AuditDetailSlideDelete`, `AuditDetailSlideReorder`. `AuditLogEntry` overrides the generated `detail` field using `Omit` + intersection. `DetailBadge` prop type updated from `Record<string, unknown>` to `AuditDetail`.

#### M-03 — CourseHistory panel does not auto-refresh
File: packages/authoring-ui/src/components/debug/CourseHistory.tsx

Issue: Panel fetches history once on mount. Mutations that happen after the panel
opens are not reflected without manual close/reopen.

Impact: LOW — Debug panel only; not user-facing data.

Fix: Add a refresh button or polling interval.

Status: FIXED — Refresh button (⟳) added to `CourseHistory` header (M-167-03). Calls `void load(skip)` to reload the current page in-place. Button disabled while loading to prevent double-fetch.
