# AICC

Package a course for AICC-compliant LMSes. AICC uses HTTP POST (HACP) instead of a JavaScript API, making it compatible with LMSes that predate SCORM.

The packager library is fully implemented; a REST endpoint is not yet exposed — use the packager programmatically.

---

## The 4-File Format

An AICC package contains four descriptor files (plus the course content):

| File | Extension | Purpose |
|---|---|---|
| Course descriptor | `.crs` | Course metadata — title, version, system ID |
| Assignable Unit | `.au` | Launch URL, mastery score, max time |
| Description | `.des` | Human-readable description per AU |
| Course Structure | `.cst` | Hierarchy of blocks and AUs |

The ZIP also includes `imsmanifest.xml` (for LMSes that expect it), `index.html`, and `player.js`.

---

## HACP Bridge

AICC LMSes communicate via HTTP POST to an LMS-provided URL. The `index.html` generated by the AICC packager embeds an HACP bridge — a small IIFE that implements `window.API` on top of `XMLHttpRequest`, translating `LMSSetValue` calls into HACP messages:

```plaintext
AICC_cmd=PutParam
AICC_data=<key>=<value>
```

The Runtime Player detects the injected `window.API` and uses it transparently — no code change needed in the player.

## Using the Packager Programmatically

```typescript
import { packAICC } from '@elearn-studio/scorm-packager'
import type { CourseDoc } from '@elearn-studio/scorm-packager'
import * as os from 'os'

const zipPath = await packAICC(course as CourseDoc, os.tmpdir(), {
  playerPath: '/path/to/player.js',   // optional
  auId:       'AU_001',               // optional — AICC Assignable Unit identifier
  fileName:   'my_course_aicc.zip',   // optional
})
```

## Descriptor File Examples

**`.crs` — Course descriptor:**

```ini
[Course]
Course_ID=ELEARN_64e1f2a3b4c5d6e7f8a9b0c1
Course_System=eLearn Studio
Course_Title=My Course

[Course_Behavior]
Max_Fields_CST=2
```

**`.au` — Assignable Unit:**

```ini
[AU]
System_ID=AU_001
Title=My Course
File_Name=index.html
Mastery_Score=80
Max_Time_Allowed=
Time_Limit_Action=
Launch_Data=
```

**`.des` — Description:**

```ini
[Description]
System_ID=AU_001
Description=My Course
```

**`.cst` — Course Structure:**

```ini
[Block]
block_0=Root

[Course_Structure]
B,0=block_0
A,1=AU_001
```

## Importing into Moodle

Moodle's SCORM activity supports AICC packages:

1. Download the AICC ZIP generated by the packager.
2. In Moodle: **Add activity → SCORM package**.
3. Upload the `.zip` file — Moodle detects the `.crs` descriptor and treats it as AICC.
4. Set **AICC HACP URL** if required by your Moodle configuration.
5. Save and test with a learner account.

> Moodle must have AICC enabled in **Site administration → Plugins → Activity modules → SCORM/AICC → AICC**.
